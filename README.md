# Kazi Rejaul Alam — Portfolio

IT Professional · Technology Mentor · Web Development. 30+ years of experience in IT, networking, systems, and digital tools.

## View
Open `index.html` in any browser, or enable GitHub Pages (Settings → Pages → Branch: main → / (root)).

## Editing
- **Admin Panel**: open `admin.html` on the live site, log in, and edit every section through a form. See `EDITING-GUIDE.md` for setup (one-time GitHub token needed).
- **Direct code edit**: edit `content.json` for text/data, `index.html` for design/layout.

## Structure
- `index.html` — the site shell (design/layout, loads text from content.json)
- `content.json` — all editable text/data (hero, about, expertise, experience, education, contact)
- `admin.html` — password-gated admin panel that edits content.json and photos directly via the GitHub API
- `EDITING-GUIDE.md` — step-by-step editing instructions (Bangla)
- `assets/hero.jpg` — hero section photo
- `assets/profile.jpg` — About section photo
